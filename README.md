# andrey-kolod.github.io

Сайт-портфолио QA-инженера Андрея Колодяжного: https://andrey-kolod.github.io

## Структура

- `index.html` — страница. Русские тексты лежат прямо в разметке.
- `pages/index.css` — все стили страницы.
- `src/index.js` — точка входа; модули в `src/modules/`:
  - `i18n.js` — переключение RU/EN (элементы с `data-i18n` и `data-i18n-attr`);
  - `translations.js` — английские тексты;
  - `nav.js` — меню на телефоне;
  - `cards.js` — переворот карточек «Артефакты»;
  - `carousel.js` — карусель фото и окно просмотра.
- `projects/CV/` — резюме: страница и PDF (печатается из этой страницы).
- `projects/mesto_project/` — учебный проект «Место Russia».

## Как добавить текст

1. Русский текст — в `index.html`, у элемента атрибут `data-i18n="ключ"`.
2. Английский — в `src/modules/translations.js` под тем же ключом.

## Запуск локально

Модули JS не работают при открытии файла двойным щелчком, нужен локальный сервер:

```bash
python -m http.server 8000
```

Затем открыть http://localhost:8000.
